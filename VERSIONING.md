# Versioning

This repository uses semantic versioning for constitutional artifacts.

## What is a breaking change
A change is breaking if it alters any of the following:
- Where authority originates
- The evaluation vs execution separation
- Any declared invariant that constrains platforms
- The meaning, scope, or required fields of a declaration

## Amendment process (summary)
- Proposed changes must be explicit, reviewable, and recorded.
- No silent drift: every change must be captured in CHANGELOG.md.
- See 06-appendices/amendment-process.md for the full process.
