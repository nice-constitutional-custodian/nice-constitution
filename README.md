# NICE Constitutional Artifacts (v0)

This repository defines the first constitutional artifact set for NICE.

It is not an implementation repository.
It is a normative documentation backlog: what must exist, why it exists, and what “done” means for each artifact.

## What this repo contains
- Constitutional planes and boundaries
- Declarations and invariants
- Hostile-reader defenses
- Standards indexes (placeholders only in v0)

## What this repo does NOT contain
- Platforms, services, SDKs, or runtime code
- Protocol choices or wiring diagrams
- Execution logic, routing mechanics, optimization, or agent behavior
